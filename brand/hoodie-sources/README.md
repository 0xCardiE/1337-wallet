# 1337 hoodie mark

`hoodie-evm.png` is the current source: pixel hood with an EVM visor.

`hoodie-eth.png` is the earlier hood + 3D Ethereum diamond.

`npm run icons` punches the near-black plate to transparency, crops to the hood, and writes `public/icons/1337-skull.png` / `.svg`. It also writes `brand/social/avatar-1024.png` — same mark on an opaque plate with padding so X / Discord / GitHub circle crops do not clip the hood. The pixel `1337` wordmark is drawn on a grid (`#00ff00`).
