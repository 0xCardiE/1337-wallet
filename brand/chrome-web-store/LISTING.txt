--- Detailed description (paste into the listing) ---

An EVM wallet for hackers. Readable confirms, easy RPC switching, approvals, swaps, ENS, and multisend. No analytics. No tracking server. Works with every MetaMask dapp.

📌 THE BASICS
- Self-custody EOA wallet on 20+ EVM chains, same address everywhere
- Works with Uniswap and every MetaMask dapp (window.ethereum drop-in + EIP-6963)
- Seed phrase, imported private keys, Ledger (WebHID), and Trezor Connect
- Side panel by default so the dapp and the signer sit side by side — or switch to a popup
- Encrypted vault in Chrome storage on this device. No 1337 account. No 1337 server

📖 READABLE CONFIRMS
- Plain-language summary before you sign
- Local simulation: pass / fail / revert / gas against the current chain
- Contract danger flags, verified-proxy hints, and decoded calldata
- Human line first, developer details underneath
- Hardware still confirms on the device

🔌 YOUR RPC, YOUR CALL
- Switch public endpoints per chain in one click, or paste a custom URL
- Network doctor probes chainId and marks healthy vs down
- Failover uses the healthy ones
- 1337 does not run an RPC of its own

🛠️ TOOLS
- Approvals — ERC-20, NFT setApprovalForAll, and Permit2. Scan and revoke
- Swap — LI.FI routes, then you sign. No extra 1337 fee
- Multisend — Disperse.app batch. No fee from the contract; leftover native is refunded
- ENS — register, renew, content hash, records
- Gas station — top up native on another chain when you are stuck
- Signings — local history of SIWE, permits, and typed data
- Inspect — paste an address, token, ENS name, or tx hash (opt-in in Settings)

⚡ NORMAL OR BURNER MODE
- Normal (default): confirm every dapp request
- Burner Mode: auto-sign ordinary requests on a disposable local key
- Risk gates still pause unlimited approvals, unknown contracts, high-value sends, permits, and SIWE mismatches unless you ungate them
- Hardware always confirms on the device

🔒 PRIVATE BY DESIGN
- Privacy is only possible when there is no central entity with the power to violate it. Other wallets keep that power. 1337 does not, and never will
- No analytics. No tracking. No telemetry. No user accounts. Never a 1337 collection server
- Vault, settings, and session stay in Chrome extension storage on the user's machine
- Network calls happen only when you use RPCs, swaps, explorers, or hardware
- History uses the explorer API key you paste in Settings — there is no 1337 history backend
https://1337wallet.io/privacy

⚠️ SELF-CUSTODY
You hold the keys. We do not guarantee, insure, or recover funds. Simulation and danger flags help you judge a request. They do not insure the outcome.
https://1337wallet.io/terms

FAQ

Q: Can I use my existing wallet with 1337?
A: Yes. Import a seed phrase or private key, or connect Ledger / Trezor. HD accounts use the same path as MetaMask (m/44'/60'/0'/0/n).

Q: Does it work with Uniswap and other dapps?
A: Yes. Enable MetaMask drop-in for sites that only look for MetaMask, or connect as 1337 via EIP-6963.

Q: How is this different from MetaMask or Rabby?
A: Same job — connect, send, sign — with denser signer tools: per-chain RPC picker and network doctor, readable confirms with local simulate, approval revoke, LI.FI swaps, multisend, ENS, side panel, and optional Burner Mode. No analytics. No 1337 server.

Q: Do you track me?
A: No. 1337 is private by design. Privacy is only possible when there is no central entity with the power to violate it — other wallets keep that power. We do not collect analytics, telemetry, or any data on a 1337 server, and we never will. Third parties you choose (RPC, LI.FI, explorer, Trezor Connect) still see what those features need.

Q: What is Burner Mode?
A: A per-wallet option that auto-signs ordinary dapp requests on a local key you treat as disposable. Risky actions still pause unless you ungate them. Hardware never auto-signs.

Q: Is it a Foundry or Etherscan replacement?
A: No. 1337 is a wallet you sign with. Inspect, History, and the confirm sheet cover “what is this address / token / tx?” Use Foundry and explorers for the lab work.
