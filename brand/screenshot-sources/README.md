# Screenshot sources

Raw popup captures used by `npm run store:frames`. Do not overwrite these with the 1280×800 billboard JPGs — the framer extracts the UI from here.

- Store shots `01-*.png` … `07-*.png` are refreshed by `npm run store:assets` (live extension + mocks).
- Site-only shots (`history.png`, `ens.png`, …) stay here until those views are added to the capture script.
